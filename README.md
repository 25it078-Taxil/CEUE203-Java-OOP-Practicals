# CEUE203 Object Oriented Programming — Complete Practical Solutions

Based on the uploaded 20-page CEUE203 practical list (A.Y. 2026–27, Semester 3). Includes Practical 1–14. Each `Practical-NN/Part-A` contains the three Part A programs as independent runnable Java files. `MiniBank-Final` is the integrated Part B capstone project covering the semester's MiniBank requirements.

## Requirements
- JDK 17+ (records, switch expressions and pattern matching are used).
- Windows: open `MiniBank-Final` and run `build.bat`, then `run.bat`.
- Linux/macOS: run `./build.sh`, then `./run.sh`.
- Tests: `test.bat` or `./test.sh`.

For any Part A program: open its `Practical-NN/Part-A` directory, run `javac FileName.java`, then `java ClassName`. Some programs prompt for input.

See each practical README and `MiniBank-Final/README.md` for details. All source is plain Java; no IDE-specific project files or external libraries required.

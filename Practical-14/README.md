# Practical 14

Part A contains three independent runnable Java programs. Part B is implemented in the shared final MiniBank project at `../../MiniBank-Final`.

Compile/run a Part A program (from this folder):

```bash
javac FileName.java
java ClassName
```

Use the matching filename/class name. Java 17 or newer is required.

For `LayeredAppTests.java`, compile it together with `LayeredApp.java`: `javac LayeredApp.java LayeredAppTests.java`, then run `java LayeredAppTests`.
